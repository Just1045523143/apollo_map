# Source provenance

Imported from this workspace's `data/imap_box_0_1_10` (imap_box 0.1.10).
The source files retain their upstream copyright and Apache-2.0 notices;
the license text is in `../LICENSE`. The original data directory is left in place.
`proto/map.desc` contains a snapshot of this Apollo checkout's map schemas;
no generated bytecode or Apollo Python packages are vendored.

Local integration changes:

- Load Apollo's current map schemas from the bundled descriptor snapshot in an isolated pool.
- Provide `python -m imap` and the repository-owned `../imap.sh` launcher.
- Load plotting dependencies only in visualization mode; CLI conversion is headless.
- Validate conversion arguments and report missing dependencies with a nonzero exit.

Traffic-light conversion now includes signal boundaries, a centre subsignal,
lane overlaps, signalReference and explicit stop-line road objects. Generic
traffic-light codes do not imply a bulb layout; their types remain UNKNOWN.
See `../SIGNAL_CONVERSION_CN.md` for supported geometry and remaining limits.
`left_road_sample/right_road_sample` remain the responsibility of the existing
Apollo map postprocessor, rather than this OpenDRIVE converter.
